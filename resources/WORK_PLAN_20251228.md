## 🔧 내일 (12/28) 작업 계획

### 핵심 변경: 2-Stage → End-to-End VRL

| 이전 (실패) | 변경 (Isaac Lab 방식) |
|-------------|----------------------|
| CNN 별도 학습 | Policy 내부에서 CNN 학습 |
| 이미지 → 3D 좌표 | 이미지 → Action 직접 |
| Supervised | End-to-End RL |

### 구현 순서

```
1. pick_place_vision_env.py 수정
   - observation = RGB-D 이미지 그대로 (224x224x4)
   - 정규화: /255, 평균 빼기
   
2. train_vision_sac.py 수정
   - CnnPolicy 사용 (Stable Baselines3)
   - observation_space = Box(0, 1, (4, 224, 224))
   
3. 테스트 실행
   - SAC with CnnPolicy
   - 충분한 스텝 (500K+)
```
