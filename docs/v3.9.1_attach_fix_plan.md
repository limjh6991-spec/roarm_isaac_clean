**작성일**: 2025-10-27 18:06  
**문제**: reach_rate=24, grip_rate=0 (100K 학습 완료 후)

---

## 🚨 근본 원인

### 1. 코드 분석
```python
# envs/roarm_pick_place_env.py - step() 함수
def step(self, action):
    # ... 액션 실행 ...
    self.world.step(render=False)
    obs = self._get_observation()
    reward = self._calculate_reward(obs)
    done = self._check_done(obs)
    # ❌ gripper.attach() 호출 없음!
    return obs, reward, done, info
```

**문제**: 
- `gripper.is_grasped()` 체크만 있고
- `gripper.attach()` 호출이 없음
- 따라서 `self.gripper.is_attached`는 항상 `False`

### 2. 로그 증거
```
🎯 REACH (+0.5)  ← 24회 달성
dist=0.020, width=0.0467, attached=False  ← 2cm까지 접근
dist=0.023, width=0.0300, attached=False  ← 그리퍼 거의 닫힘
🤝 ATTACH (+50.0)  ← 0회! (호출되지 않음)
```

**문제**:
- 거리: 2-3cm ✅ (충분히 가까움)
- 그리퍼: 3-4.5cm ✅ (닫으려고 시도)
- **attached=False** ❌ (물리적 부착 실패)

## ✅ 해결 방안

### A. step() 함수에 Attach 로직 추가

```python
# envs/roarm_pick_place_env.py - step() 함수 수정

def step(self, action: np.ndarray) -> Tuple[np.ndarray, float, bool, Dict]:
    """환경 스텝 실행"""
    
    # ... (기존 액션 실행 코드) ...
    
    self.world.step(render=False)
    
    # 🔥 v3.9.1 FIX: Attach 로직 추가
    # 현재 상태 가져오기
    joint_positions = self.robot.get_joint_positions()
    ee_pos = self._get_ee_position()
    cube_pos = self.cube.get_world_pose()[0]
    gripper_width = self.gripper.measure_width(joint_positions)
    
    # Grasp 조건 체크
    is_grasping = self.gripper.is_grasped(
        ee_pos, 
        cube_pos, 
        gripper_width,
        cube_size=0.04,      # 4cm 큐브
        dist_tol=0.03,       # 3cm 거리 허용
        z_tol=0.015,         # 1.5cm Z축 정렬
        width_margin=0.006   # ±6mm 그리퍼 폭 여유
    )
    
    # Attach/Detach 처리
    if is_grasping and not self.gripper.is_attached:
        # 조건 만족 → 부착
        self.gripper.attach(
            self.world.stage,
            self.ee_prim_path,          # gripper_base 경로
            "/World/DynamicCube",       # 큐브 경로
            timestep=self.step_count
        )
    elif not is_grasping and self.gripper.is_attached:
        # 조건 불만족 → 분리
        self.gripper.detach(self.world.stage)
        self.gripper.detach_called_this_step = True
    else:
        self.gripper.detach_called_this_step = False
    
    # 관측 및 보상 계산
    obs = self._get_observation()
    reward = self._calculate_reward(obs)
    done = self._check_done(obs)
    
    self.current_step += 1
    self.step_count += 1
    
    # ... (info 생성) ...
    
    return obs, reward, done, info
```

## 💡 핵심 교훈

### 1. False Positive 방지의 역설
- **의도**: "물리적 부착만 인정" (is_attached)
- **구현 누락**: attach() 호출 없음
- **결과**: 아무도 성공할 수 없음

- 보상 함수 변경 시 **전체 흐름 검증** 필요
- 조건 체크만 있고 **액션 실행 누락** 위험
- 단위 테스트 필수

### 3. 로그 기반 디버깅
- `attached=False` 로그 100% 일관성
- 의심 포인트: "왜 한 번도 True가 안 나올까?"
- 코드 추적 → attach() 호출 없음 발견
