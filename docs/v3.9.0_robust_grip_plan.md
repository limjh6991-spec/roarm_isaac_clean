# v3.9.0 개선 계획 - Robust GRIP 정의 (False Positive 방지)

**작성일**: 2025-10-27  
**목적**: 성공 정의를 물리적으로 강한(robust) AND 게이트로 변경  
**문제**: v3.8.1에서도 "접근만으로 성공" 판정되는 False Positive 존재

---

## 🚨 현재 문제 (v3.8.1)

### False Positive 발생 원인
```python
# 현재 (v3.8.1) - 여전히 약함
grasp_valid = (
    dist_to_cube < 0.03 and            # 3cm 이내
    (0.030 < gripper_width < 0.050) and # 그리퍼 너비만 체크
    abs(cube_relative_to_ee[2]) < 0.015 # Z축 정렬
)

문제점:
✗ 접촉 확인 없음 (가까이만 가면 성공)
✗ 그리퍼 닫기 의도 미확인
✗ 물리적 부착 상태 미확인
✗ 리프트 조건과 분리됨
→ 결과: 지표는 좋은데 실제로는 안 잡음 (False Positive)
```

---

## ✅ 해결 방안 (v3.9.0)

### 핵심 원칙
```yaml
성공은 시간적·물리적 조건을 동시에 만족:
  1. 접근 (Reach): dist < 5cm [필수지만 단독으론 성공 아님]
  2. 접촉 (Contact): 그리퍼 팁과 큐브 동시 접촉
  3. 닫기 의도 (Closing): Δwidth < 0 (닫는 중)
  4. 부착 (Attach): self.gripper.is_attached == True
  5. 리프트 (Lift): Δz_cube > 2cm
  6. 홀드 (Hold): 위 상태 N 프레임 연속 유지

진짜 성공 = (4 Attach) AND (5 Lift) AND (6 Hold)
```

### 단계별 지표 (모두 기록)
```python
# 로그에 분리 기록
reach_rate = P(dist < 5cm)               # 접근 성공률
contact_rate = P(contacts >= 2 | reach)  # 접촉 성공률 (접근 시)
closing_rate = P(Δwidth < 0 | reach)     # 닫기 시도율 (접근 시)
attach_rate = P(is_attached)             # 물리적 부착률
lift_rate = P(Δz > 2cm | attach)         # 리프트 성공률 (부착 시)
success_rate = P(attach & lift & hold)   # 최종 성공률 ← 유일한 진짜 성공

혼동 행렬:
  pred_success (기존 GRIP) vs true_success (attach & lift & hold)
  False Positive 비율 = FP / (TP + FP)
```

### 2. 단계별 지표 추적
```python
# 에피소드별 추적
self.episode_metrics = {
    'reach': False,        # dist < 5cm
    'contact': False,      # contacts >= 2
    'closing': False,      # Δwidth < 0
    'attach': False,       # is_attached
    'lift': False,         # Δz > 2cm
    'hold': False,         # N 프레임 유지
    'success': False       # attach & lift & hold
}

# 매 스텝 업데이트
if dist_to_cube < 0.05:
    self.episode_metrics['reach'] = True
    
if self.gripper.is_attached:
    self.episode_metrics['attach'] = True
    
if self.gripper.is_attached and cube_pos[2] > initial_z + 0.02:
    self.episode_metrics['lift'] = True
    self.lift_hold_frames += 1
    if self.lift_hold_frames >= 10:
        self.episode_metrics['hold'] = True
        self.episode_metrics['success'] = True  # ← 유일한 진짜 성공
```

### 3. 로그 출력 개선
```python
# 100 에피소드마다
if episode % 100 == 0:
    reach_rate = sum(metrics['reach']) / 100
    attach_rate = sum(metrics['attach']) / 100
    lift_rate = sum(metrics['lift']) / 100
    success_rate = sum(metrics['success']) / 100  # ← 진짜 성공률
    
    # 혼동 행렬
    pred_success = sum(metrics['attach'])  # 기존 GRIP
    true_success = sum(metrics['success']) # attach & lift & hold
    false_positive = pred_success - true_success
    fp_rate = false_positive / pred_success if pred_success > 0 else 0
    
    print(f"""
    📊 Episode {episode} Metrics:
    ├─ Reach:   {reach_rate:.1%}
    ├─ Attach:  {attach_rate:.1%}  ← 물리적 부착
    ├─ Lift:    {lift_rate:.1%}    ← 리프트 성공
    └─ Success: {success_rate:.1%} ← 진짜 성공 (attach & lift & hold)
    
    ⚠️ False Positive: {fp_rate:.1%}
       (Attach했지만 Lift 못함)
    """)
```

## 📊 보상 구조 재설계

### A. Dense Reward (탐색 유도 - 느슨)
```python
# 1. EE → Cube 접근 (계속 유지)
reward += 20.0 * (prev_dist - curr_dist)  # 개선량

# 2. 그리퍼 닫기 장려 (계속 유지)
if dist_to_cube < 0.10:  # 10cm 이내
    if delta_width < 0:  # 닫는 중
        reward += 5.0 * abs(delta_width)
    
    # Width 최적화 (4cm 선호)
    width_error = abs(gripper_width - 0.04)
    reward -= 3.0 * width_error
```

### B. Milestone Reward (엄격 - 평가)
```python
# 🔥 v3.9.0: 성공 정의 엄격화
REWARD_REACH = 0.5      # 접근 (유지)
REWARD_ATTACH = 50.0    # 물리적 부착 ← NEW!
REWARD_LIFT = 15.0      # 리프트 (유지)
REWARD_SUCCESS = 50.0   # 최종 성공 (attach & lift & hold)

# 1️⃣ REACH (느슨 - 탐색 유도)
if not self.first_reach and dist_to_cube < 0.05:
    reward += REWARD_REACH
    self.first_reach = True
    print(f"  🎯 REACH (+{REWARD_REACH})")

# 2️⃣ ATTACH (엄격 - 물리적 부착만)
if not self.first_attach and self.gripper.is_attached:
    reward += REWARD_ATTACH
    self.first_attach = True
    self.episode_metrics['attach'] = True
    print(f"  🤝 ATTACH (+{REWARD_ATTACH}) ← 물리적 부착!")

# 3️⃣ LIFT (엄격 - attach 후에만)
if not self.first_lift and self.gripper.is_attached:
    if cube_pos[2] > self.initial_cube_z + 0.02:
        reward += REWARD_LIFT
        self.first_lift = True
        self.episode_metrics['lift'] = True
        print(f"  ⬆️ LIFT (+{REWARD_LIFT})")

# 4️⃣ SUCCESS (최종 - hold 포함)
if self.gripper.is_attached and self.first_lift:
    self.lift_hold_frames += 1
    if self.lift_hold_frames >= 10 and not self.success:
        reward += REWARD_SUCCESS
        self.success = True
        self.episode_metrics['success'] = True
        print(f"  🏆 SUCCESS (+{REWARD_SUCCESS}) ← 진짜 성공!")
else:
    self.lift_hold_frames = 0
```

### 빠른 검증 (5분)
```python
# scripts/rl/validate_grip.py
def validate_grip_quality(model_path, n_episodes=50):
    """GRIP 품질 검증 (False Positive 탐지)"""
    
    metrics = {
        'reach': [],
        'attach': [],
        'lift': [],
        'success': []
    }
    
    for ep in range(n_episodes):
        obs = env.reset()
        done = False
        
        ep_reach = False
        ep_attach = False
        ep_lift = False
        ep_success = False
        
        while not done:
            action, _ = model.predict(obs, deterministic=True)
            obs, reward, done, info = env.step(action)
            
            # 단계별 체크
            if info['dist_to_cube'] < 0.05:
                ep_reach = True
            if env.gripper.is_attached:
                ep_attach = True
            if ep_attach and info['cube_z'] > info['initial_z'] + 0.02:
                ep_lift = True
            if ep_lift and info['hold_frames'] >= 10:
                ep_success = True
        
        metrics['reach'].append(ep_reach)
        metrics['attach'].append(ep_attach)
        metrics['lift'].append(ep_lift)
        metrics['success'].append(ep_success)
    
    # 분석
    reach_rate = np.mean(metrics['reach'])
    attach_rate = np.mean(metrics['attach'])
    lift_rate = np.mean(metrics['lift'])
    success_rate = np.mean(metrics['success'])
    
    # False Positive 계산
    false_positives = sum(metrics['attach']) - sum(metrics['success'])
    fp_rate = false_positives / sum(metrics['attach']) if sum(metrics['attach']) > 0 else 0
    
    print(f"""
    ╔════════════════════════════════════════╗
    ║  GRIP Quality Validation ({n_episodes} episodes) ║
    ╠════════════════════════════════════════╣
    ║  Reach:   {reach_rate:6.1%}                      ║
    ║  Attach:  {attach_rate:6.1%} ← 물리적 부착       ║
    ║  Lift:    {lift_rate:6.1%} ← 리프트 성공        ║
    ║  Success: {success_rate:6.1%} ← 진짜 성공        ║
    ╠════════════════════════════════════════╣
    ║  False Positive: {fp_rate:6.1%}              ║
    ║  (Attach했지만 Success 못함)           ║
    ╚════════════════════════════════════════╝
    
    {'✅ GOOD: FP < 5%' if fp_rate < 0.05 else '⚠️ BAD: FP > 5% - 성공 정의 더 조여야 함'}
    """)
    
    return metrics
```

