## 🚀 다음 작업 계획

### Priority 1: GRIP 조건 재조정 ⭐
**목표**: GRIP 성공률 30% → 60%+

**방법**: 조건을 현실적으로 완화
```python
# 현재 (v3.0 - 너무 엄격)
is_grasped = dist < 0.05 and width < 0.03 and z_diff < 0.02

# 제안 (v3.1 - 현실적)
is_grasped = dist < 0.08 and width < 0.04 and z_diff < 0.03
```

**예상 소요 시간**: 코드 수정 10분 + 학습 100K (4분) = 15분

### Priority 2: Z축 접근 보상 추가
**목표**: 로봇이 큐브와 높이를 맞추도록 유도

**방법**: Z축 정렬 보상 추가
```python
# 큐브와 높이를 맞추는 행동에 보상
z_alignment_reward = max(0, 0.05 - abs(z_diff)) * 5.0
reward += z_alignment_reward
```

**예상 효과**: z_diff 0.04 → 0.02로 개선

### Priority 3: 그리퍼 제어 학습 강화
**목표**: 가까울 때 그리퍼를 닫도록 학습

**방법**: 거리 기반 그리퍼 제어 보상
```python
# 큐브에 가까울 때 그리퍼 닫기 유도
if dist < 0.10:
    target_width = 0.02  # 목표: 2cm (큐브 크기 4cm의 절반)
    gripper_reward = -abs(gripper_width - target_width) * 3.0
    reward += gripper_reward
```

**예상 효과**: 그리퍼 제어가 더 정밀해짐

### Priority 4: 단계별 Curriculum (선택)
**목표**: 각 스킬을 순차적으로 학습

**방법**:

```python
# Phase 0: REACH만 학습 (그리퍼 고정 열림, 20K steps)
# Phase 1: REACH + GRIP 학습 (80K steps)
# Phase 2: REACH + GRIP + LIFT 학습 (100K steps)
```
