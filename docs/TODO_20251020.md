  - 좌우 대칭 구조

#### 1.3 URDF 수정
**수정 방향:**
1. **Gripper 조인트 타입 수정**
   - 현재: Fixed 또는 잘못된 타입
   - 수정: Prismatic (직선 이동)

2. **조인트 이름 명확화**
   ```xml
   <joint name="gripper_left_joint" type="prismatic">
     <parent link="link_5"/>
     <child link="gripper_left_finger"/>
     <axis xyz="0 1 0"/>  <!-- Y축 방향 -->
     <limit lower="0.0" upper="0.025" effort="10" velocity="0.1"/>
   </joint>
   
   <joint name="gripper_right_joint" type="prismatic">
     <parent link="link_5"/>
     <child link="gripper_right_finger"/>
     <axis xyz="0 -1 0"/>  <!-- 반대 방향 -->
     <limit lower="0.0" upper="0.025" effort="10" velocity="0.1"/>
     <origin xyz="0 0 0" rpy="0 0 0"/>
   </joint>
   ```

3. **Link 크기 실제 사양 반영**
   ```xml
   <link name="link_2">
     <visual>
       <geometry>
         <cylinder length="0.16" radius="0.02"/>  <!-- 160mm -->
       </geometry>
     </visual>
   </link>
   ```
