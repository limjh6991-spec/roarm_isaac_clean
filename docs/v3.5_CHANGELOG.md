## 🔧 6가지 핵심 수정

### FIX #1: EE 위치 정확도 향상 ✅
**문제**: 하드코딩된 Forward Kinematics로 EE 위치 근사
- Link 길이 하드코딩 (link2=0.16m, link3=0.15m 등)
- 단순 삼각함수 계산으로 실제와 오차 발생
- dist_to_cube, z_alignment 값 부정확

**해결**: USD prim에서 실제 월드 포즈 직접 추출
```python
def _get_ee_position(self) -> np.ndarray:
    # USD에서 gripper_base의 실제 변환 행렬 추출
    gripper_prim = stage.GetPrimAtPath(f"{prim_path}/gripper_base")
    xformable = UsdGeom.Xformable(gripper_prim)
    world_transform = xformable.ComputeLocalToWorldTransform(0)
    
    # 변환 행렬에서 위치 벡터 추출
    ee_pos = np.array([
        world_transform[3][0],
        world_transform[3][1], 
        world_transform[3][2]
    ])
    return ee_pos
```

**효과**: EE 위치 정확도 mm 단위 → 엄격한 GRIP 게이팅 작동 가능

### FIX #2: GRIP 판정 로직 변경 ✅
**문제**: `gripper_width < 0.015` (1.5cm)는 "빈 집게"만 긍정
- 큐브 폭: 4cm
- 큐브를 끼운 상태: gripper_width ≈ 4cm
- 기존 조건: 4cm > 1.5cm → False (항상 실패!)

**해결**: "그리퍼 폭 ≈ 큐브 폭" 방식으로 변경
```python
CUBE_WIDTH = 0.04  # 4cm
is_grasping_cube = (0.035 < gripper_width < 0.045)  # 3.5~4.5cm

is_grasped = (
    dist < 0.03 and         # 3cm 근접
    is_grasping_cube and    # 🔥 큐브를 끼운 상태!
    z_diff < 0.01           # 1cm Z축 정렬 (5mm→1cm 완화)
)
```

**효과**: 
- v3.4: "빈 집게로 닫힌 상태" 요구 → 불가능
- v3.5: "큐브를 끼운 상태" 요구 → 실제 작업 반영

### FIX #3: Prismatic Joint Drive 수정 ✅
**문제**: 모든 조인트에 `DriveAPI.Apply(joint, "angular")` 적용
- Revolute joint: ✅ 정상
- Prismatic joint (그리퍼): ❌ 선형 운동에 회전 드라이브!

**해결**: Joint 타입별 구분 적용
```python
for joint_name in self.joint_names:
    is_gripper = ("gripper" in joint_name)
    
    if is_gripper:
        # Prismatic → LINEAR drive
        drive_api = UsdPhysics.DriveAPI.Apply(joint_prim, "linear")
        drive_api.GetStiffnessAttr().Set(8000.0)   # 강한 죄는 힘
        drive_api.GetDampingAttr().Set(800.0)
        drive_api.GetMaxForceAttr().Set(50.0)      # 🔥 8N → 50N
    else:
        # Revolute → ANGULAR drive
        drive_api = UsdPhysics.DriveAPI.Apply(joint_prim, "angular")
```

**효과**: 그리퍼가 실제로 죄어짐 (8N → 50N MaxForce)

### FIX #4: 고마찰 Physics Material 적용 ✅
**문제**: 큐브와 그리퍼에 마찰계수 설정 없음
- 기본값 (low friction) 사용 시 미끄러짐
- 닫혀도 큐브가 빠져나감

**해결**: 고마찰 Material 생성 및 바인딩
```python
# HighFriction Material 생성
physx_material = PhysxSchema.PhysxMaterialAPI.Apply(mat_prim)
physx_material.CreateStaticFrictionAttr().Set(1.2)   # Static
physx_material.CreateDynamicFrictionAttr().Set(1.0)  # Dynamic
physx_material.CreateRestitutionAttr().Set(0.1)      # 낮은 반발

# 큐브에 바인딩
material_binding_api = UsdPhysics.MaterialBindingAPI.Apply(cube_prim)
material_binding_api.Bind(mat_prim)
```

**효과**: 
- 마찰력 강화 → 큐브 안정적으로 고정
- 낮은 반발 → 떨림 최소화

### FIX #5: FixedJoint Attach 시스템 ✅
**문제**: 접촉 물리만으로 집기 어려움
- 초기 학습 단계에서 접촉력 부족
- 미세한 정렬 오차로 미끄러짐
- LIFT 단계 학습 불가능

**해결**: 조건 충족 시 임시 고정 조인트 생성
```python
def _manage_grasp_attach(self, grasp_valid: bool):
    if grasp_valid and not self.is_attached:
        # FixedJoint 생성
        joint_prim = stage.DefinePrim(path, "PhysicsFixedJoint")
        fixed_joint = UsdPhysics.FixedJoint(joint_prim)
        
        # Body0: gripper_base
        fixed_joint.CreateBody0Rel().SetTargets([gripper_path])
        # Body1: cube  
        fixed_joint.CreateBody1Rel().SetTargets([cube_path])
        
        self.is_attached = True
    
    elif not grasp_valid and self.is_attached:
        # FixedJoint 제거
        stage.RemovePrim(self.grasp_joint_path)
        self.is_attached = False
```

**효과**:
- 학습 안정화 (접촉 물리 우회)
- "집은 상태" 보장 → LIFT 학습 가능
- Detach도 자동 → 자연스러운 Place 단계 이행

### FIX #6: 그리퍼 액션 속도 증가 ✅
**문제**: 그리퍼 delta = 0.005m/step (5mm/step)
- 600 스텝 안에 접근 + 정렬 + 닫힘 어려움
- 느린 반응 → 타이밍 맞추기 실패

**해결**: Delta 2배 증가
```python
# v3.4: max_deltas = [0.1, ..., 0.005, 0.005]
# v3.5: max_deltas = [0.1, ..., 0.01, 0.01]  # 🔥 2x
```

**효과**: 
- 5mm/step → 10mm/step
- 빠른 그리퍼 반응 → 기회 포착 가능

- 마찰: 1.2/1.0 (안정)
- Attach: FixedJoint (보장)
- 속도: 10mm/step (빠름)
