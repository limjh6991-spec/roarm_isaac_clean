## 💡 해결 방안

### 1. Attach 조건 완화
```python
# 변경 전 (v3.9.1)
dist_tol=0.03,        # 3cm
width_margin=0.006    # ±6mm (3.4-4.6cm)

# 변경 후 (v3.9.2)
dist_tol=0.05,        # 5cm (2cm 완화)
width_margin=0.008    # ±8mm (3.2-4.8cm)
```

**근거**:
- 로봇이 6.4cm까지 접근 달성 (75% 진전)
- 조건을 5cm로 완화하면 즉시 진입 가능
- 물리적 부착 후 안정화는 FixedJoint가 보장

### 2. 근접 보상 강화
```python
# 기존 (v3.9.1)
distance_reward = max(0, 0.3 - dist) * 10.0

# 추가 (v3.9.2)
if dist < 0.03:
    reward += 20.0  # 3cm 이하 강력 보상!
```

**근거**:
- 6.4cm → 3cm 추가 접근 동기 부여
- 3cm 진입 시 총 보상 +27 (기존 +7)
- Attach 조건 만족 확률 증가
